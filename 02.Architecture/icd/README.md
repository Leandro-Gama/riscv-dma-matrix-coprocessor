# ICD — contrato de interfaces

Fonte da verdade para portas, protocolos, temporização, mapa de memória e mapa de registradores entre CPU, DMA, acelerador e sistema. É produzido no E1 e versionado; cada mudança referencia o ADR que a justificou.

Nenhum bloco muda uma porta descrita aqui sem ADR aprovado pelos donos afetados.
