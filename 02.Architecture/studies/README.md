# Estudos de arquitetura

Cada estudo responde a um conjunto de perguntas do E1. A estrutura é sempre a mesma:

1. as alternativas consideradas;
2. os critérios (de `requirements.md`);
3. a evidência, seja ela números do modelo de ciclos, estimativas ou impacto em cada bloco;
4. a recomendação.

A decisão em si vai para um ADR em [../decisions/](../decisions/).

Nome dos arquivos: `NN_<tema>.md`.
